# Smart Shopping Centre 🛍️

একটি সম্পূর্ণ স্ট্যাটিক ই-কমার্স ফ্রন্টএন্ড — HTML, CSS ও ভ্যানিলা JavaScript দিয়ে তৈরি। GitHub Pages-এ ফ্রি হোস্ট করা যায়, কোনো ব্যাকএন্ড/সার্ভার লাগবে না।

## ফিচার
- সার্চ বক্স (নাম/ক্যাটাগরি অনুযায়ী লাইভ ফিল্টার)
- ক্যাটাগরি চিপ ও হেডার ড্রপডাউন থেকে প্রোডাক্ট ফিল্টার
- কার্টে যোগ/বাদ, পরিমাণ বাড়ানো-কমানো, সাবটোটাল-ডেলিভারি-সর্বমোট হিসাব
- চেকআউট ফর্ম (নাম, ফোন, ঠিকানা, পেমেন্ট পদ্ধতি) ও অর্ডার কনফার্মেশন
- ১১টি রঙ মিশিয়ে তৈরি অ্যানিমেটেড গ্র্যাডিয়েন্ট ব্র্যান্ড হেডলাইন
- মোবাইল-রেসপন্সিভ লেআউট

## ফাইল স্ট্রাকচার
```
smart-shopping-centre/
├── index.html          # মূল পেজ
├── style.css            # সব স্টাইল

├── assets/

│   └── hero-illustration.svg
└── README.md
```

## নিজের প্রোডাক্ট বসানো
`script.js` ফাইলের একদম উপরের দিকে `products` অ্যারেতে আপনার প্রোডাক্টের নাম, ক্যাটাগরি ও দাম বসান। ক্যাটাগরির নাম অবশ্যই `CATEGORY_ICONS`-এ থাকা নামের সাথে মিলতে হবে (ঘড়ি, টি-শার্ট, শার্ট, প্যান্ট, জুতা, ব্যাগ), অথবা নতুন ক্যাটাগরি যোগ করলে তার জন্য একটি নতুন SVG আইকনও যোগ করুন।

## GitHub-এ আপলোড করার ধাপ

### ১. রিপোজিটরি তৈরি করুন
1. [github.com](https://github.com)-এ লগইন করুন
2. উপরে ডান পাশে **+** আইকনে ক্লিক করে **New repository** নির্বাচন করুন
3. নাম দিন (যেমন `smart-shopping-centre`), **Public** সিলেক্ট করুন, তারপর **Create repository**

### ২. কোড আপলোড করুন
**অপশন A — ব্রাউজার থেকে (সহজ):**
1. নতুন রিপোতে **Add file → Upload files** ক্লিক করুন
2. `index.html`, `style.css`, `script.js`, `README.md` এবং `assets` ফোল্ডার টেনে (drag & drop) ছাড়ুন
3. নিচে **Commit changes** ক্লিক করুন

**অপশন B — Git কমান্ড দিয়ে:**
```bash
cd smart-shopping-centre
git init
git add .
git commit -m "Smart Shopping Centre: প্রথম কমিট"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/smart-shopping-centre.git
git push -u origin main
```

### ৩. GitHub Pages চালু করুন
1. রিপোজিটরির **Settings** ট্যাবে যান
2. বাম পাশের মেনু থেকে **Pages** সিলেক্ট করুন
3. **Branch** এর নিচে `main` এবং ফোল্ডার `/root` সিলেক্ট করে **Save** করুন
4. ১-২ মিনিট পর উপরে একটি লিংক দেখাবে — যেমন:
   `https://<আপনার-ইউজারনেম>.github.io/smart-shopping-centre/`
5. এই লিংকেই আপনার লাইভ ওয়েবসাইট চলবে

## আসল পেমেন্ট/অর্ডার সিস্টেম যোগ করতে চাইলে
এই সাইটটি স্ট্যাটিক (কোনো সার্ভার নেই), তাই চেকআউট এখন শুধু একটি ডেমো কনফার্মেশন দেখায়, আসলে টাকা কাটে না বা ডেটাবেজে অর্ডার সেভ হয় না। বাস্তব লেনদেনের জন্য পরে যা যোগ করতে হবে:
- **পেমেন্ট গেটওয়ে:** bKash, Nagad বা SSLCommerz-এর মার্চেন্ট API (এর জন্য একটি ব্যাকএন্ড সার্ভার/সার্ভারলেস ফাংশন লাগবে)
- **অর্ডার সংরক্ষণ:** Firebase, Supabase বা নিজের ডেটাবেজ
- **ইমেইল/SMS নোটিফিকেশন:** অর্ডার কনফার্ম হলে গ্রাহককে জানানোর জন্য

এই ধাপগুলোর জন্য পরবর্তীতে সহায়তা প্রয়োজন হলে জানাবেন।
